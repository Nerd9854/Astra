Welcome to Astral Space Laboratory
ASTRA is built up from a core of a IAS15 simulation of the solar system with a focus on accuray. Users are able to add in a theoretical spacecraft into the scene and plan real missions with real data. This is still a work in progress and is still ebing updated. All guidance needed is already packed with the project.
